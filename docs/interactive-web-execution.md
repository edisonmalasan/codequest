# Interactive web execution (R07A)

Status: **development review only**. The synthetic `/editor-workspace` route can opt into `IsolatedInteractiveWebAdapter`; no published Quest selects it. Run, local Check, and backend submission remain separate. The static preview retains its script-disabled child.

## Supported exercise subset

An identified snapshot contains one HTML file, one JavaScript file, and optionally one CSS file. Starting the mode copies file IDs, source, and content version before execution. An edit marks the displayed result stale and clears the session. Reload starts a fresh Worker from the last captured snapshot only while the source remains unchanged. Cancellation, owner change, route unmount, failed handshake, error, and timeout clear active work; the editor and device-local draft remain.

Learner JavaScript runs in a fresh Worker on the credential-free runner origin. The fixed bootstrap transfers a private result/event port to its Worker before running source and rejects any result on the global Worker message channel. It receives a deliberately small `document` facade: simple ID, class, or tag selectors through `querySelector`, `querySelectorAll`, and `getElementById`; `textContent`; `classList` add/remove/contains/toggle; `getAttribute` and `setAttribute` for `title` and `aria-label`; the `color`, `backgroundColor`, `display`, and `fontSize` style properties; text-input `value`; click/input/change listeners; and bounded `console.log/info/warn/error/debug`. A selector outside that grammar or an unsupported mutation fails with bounded feedback. This is not a complete browser DOM. `innerHTML`, element creation, arbitrary attributes/style, network, storage, timers, dynamic import, nested Workers, navigation, and native `window`/`document` authority are not part of the supported subset. Original exercise content must target the declared subset.

The preview origin receives sanitized HTML/CSS and only fixed bridge code. A nested `sandbox="allow-scripts"` child omits `allow-same-origin`, form, popup, download, and navigation permissions. The child is opaque and does **not** evaluate learner JavaScript. Fixed bridge code prevalidates each mutation batch and applies only correlated, allowlisted text/class/attribute/style/input-value data mutations. Click/input/change records carry a bounded increasing sequence number. The application communicates with runner and preview bootstraps over separate private ports after exact window, origin, and bootstrap-ID checks. A child packet also needs its exact window, nonce, current generation, type, and bounded target. A matching `origin: null` alone does not authenticate it.

| Limit | Value |
| --- | ---: |
| HTML / CSS / JavaScript UTF-8 source | 64 / 32 / 64 KiB |
| Generated display document | 128 KiB |
| Elements / nesting depth | 512 / 32 |
| Events / mutations per session | 64 / 256 |
| Event or mutation packet / emitted mutations | 16 / 128 KiB |
| Console entries / output | 200 / 12 KiB |
| Initial source or each event deadline | 2 seconds |
| Initial isolated-origin handshake | 5 seconds |
| Fresh finite run after a stopped loop | 1 second |
| Session lifetime | 5 minutes |

These limits are fixed by the adapter and bootstraps. The Worker terminates on timeout, output/protocol failure, cancellation, supersession, disposal, or session expiry. Browsers provide no dependable hard per-Worker memory quota; bounded input and termination do not prove one.
