## Goal

Read text input during an input event and show an empty-state message.

## Learn

An `input` event fires as text changes. Read the supplied input node’s `value` inside the listener. When it is empty, keep a meaningful fallback in the status paragraph. A label wraps the input so its purpose remains available to assistive technology.

## Worked example

```js
const input = document.getElementById('name');
input.addEventListener('input', () => {
  document.getElementById('message').textContent = input.value || 'No name';
});
```
