## Goal

Respond to a change event with confirmed or empty feedback.

## Learn

The bounded `change` event represents committing a text field value. Read the input’s current `value` in the callback. Keep the confirmation separate from the raw input so the learner receives a clear result.

## Worked example

```js
const field = document.getElementById("field");
field.addEventListener("change", () => { document.getElementById("result").textContent = "Saved: " + field.value; });
```
