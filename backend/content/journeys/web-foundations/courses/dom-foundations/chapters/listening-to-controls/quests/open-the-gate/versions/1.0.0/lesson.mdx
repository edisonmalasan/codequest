## Goal

Respond to a button click with a visible status change.

## Learn

Register a click listener on the supplied button. The callback runs when the learner clicks the button in the preview or when a Check sends a declared click. Keep the initial closed message until the click happens.

## Worked example

```js
document.getElementById('button').addEventListener('click', () => {
  document.getElementById('message').textContent = 'Clicked';
});
```
