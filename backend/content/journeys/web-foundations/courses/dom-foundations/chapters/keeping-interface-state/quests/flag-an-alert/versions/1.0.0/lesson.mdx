## Goal

Connect class state to a readable alert message.

## Learn

A class can communicate visual state while text communicates the same state without color. `classList.add` and `classList.remove` are supported on supplied nodes. The current Checks observe the text message; inspect the class change yourself in Run. Class state is not independently graded.

## Worked example

```js
const message = document.getElementById("message");
message.classList.add("active");
message.textContent = "Active";
```
