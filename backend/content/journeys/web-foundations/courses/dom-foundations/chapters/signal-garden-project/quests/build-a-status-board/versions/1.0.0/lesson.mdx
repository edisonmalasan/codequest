## Goal

Combine input, click state, and accessible feedback in one status board.

## Learn

A small interface combines a named input, an action, and a status message. Read the input on each click instead of remembering a previous value. Keep the empty case useful and make repeated saves replace the previous message. The supplied `role="status"` makes feedback available without relying on color.

## Worked example

```js
button.addEventListener("click", () => { status.textContent = field.value ? "Saved: " + field.value : "Nothing to save"; });
```

## Your task

On Save, show `Saved plot: <value>` for a nonempty name or `Enter a plot name` for empty input. A later Save must show the latest name. Do not change the initial `No plot saved` before any click.

The preview displays sanitized supplied HTML and CSS. Your JavaScript runs in an isolated Worker through a limited page facade. It cannot use a full DOM, network, browser storage, or an arbitrary script-capable preview. Keep your source below the run limit; the project is local to this exercise.
