## Goal

Distinguish empty, in-range, and out-of-range text input.

## Learn

A status board needs a response for missing data as well as valid data. On input, read the field value. Treat empty text as missing. Convert nonempty text with `Number` and classify finite values from 0 through 100 as in range. The supported facade exposes the input value and text status, not a full form API.

## Worked example

```js
const field = document.getElementById('sample-field');
const status = document.getElementById('sample-status');
const number = Number(field.value);
status.textContent =
  field.value === '' ? 'Missing' : number > 10 ? 'High' : 'Ready';
```
