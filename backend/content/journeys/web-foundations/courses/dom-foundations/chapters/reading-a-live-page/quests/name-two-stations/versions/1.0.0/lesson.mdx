## Goal

Select two supplied paragraphs by ID and give each a distinct name.

## Learn

The supplied page has two paragraph IDs. `document.getElementById("north")` returns the first paragraph. Assign its `textContent` to replace visible text. Do the same for the second ID. The browser facade supports these operations without giving your code a full browser document.

## Worked example

```js
const heading = document.getElementById("title");
heading.textContent = "Garden notes";
```
