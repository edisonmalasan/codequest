## Goal

Use one class selection to update multiple supplied sensors.

## Learn

`document.querySelectorAll(".sensor")` finds each matching node. Use a bounded loop over the returned list, reading each existing label and replacing `waiting` with `ready`. This keeps the A and B names that are already present.

## Worked example

```js
const notes = document.querySelectorAll(".note");
for (const note of notes) { note.textContent = note.textContent + " checked"; }
```
