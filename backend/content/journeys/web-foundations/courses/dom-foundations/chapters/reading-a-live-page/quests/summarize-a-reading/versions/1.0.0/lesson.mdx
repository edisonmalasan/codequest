## Goal

Read supplied text and reuse it in another page element.

## Learn

`textContent` can be read as well as changed. Read the supplied measurement from `#reading`, then build a sentence in `#summary`. The measurement is already on the page; do not hardcode a replacement number.

## Worked example

```js
const label = document.getElementById('label');
const copied = label.textContent;
document.getElementById('copy').textContent = 'Copy: ' + copied;
```
