## Goal

Divide a page into header, main, and footer regions.

## Learn

Landmarks make the main parts of a page recognizable without relying on visual position. A header introduces this page, main contains its central task, and footer holds closing information. Keep the page’s main content in one main region. Landmark elements do not require special styling to be meaningful.

## Worked example

```html
<header><h1>Notes</h1></header>
<main><p>Today...</p></main>
<footer><p>End of notes</p></footer>
```
