## Goal

Use table headers to identify columns of simple data.

## Learn

A table is useful when rows and columns make facts easier to compare. Use th for a column heading and td for a data cell. Keep the table small and readable here; do not use it merely to position a page. Someone reading cell by cell needs the headers to understand what each value means.

## Worked example

```html
<table>
  <tr>
    <th>Day</th>
    <th>Weather</th>
  </tr>
  <tr>
    <td>Monday</td>
    <td>Cloudy</td>
  </tr>
</table>
```
