## Goal

Keep an illustration and its explanation together.

## Learn

A figure groups a visual with context that belongs to it. Its figcaption explains what the reader should notice; the image alt describes the essential visual content. These can complement each other instead of repeating the same words. The supplied local icon is bounded data and does not make a network request.

## Worked example

```html
<figure>
  <img src="data:image/png;base64,..." alt="Two paths meet" />
  <figcaption>Trail junction</figcaption>
</figure>
```
