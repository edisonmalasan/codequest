## Goal

Choose ordered and unordered lists for different kinds of information.

## Learn

Use ul when the items belong together but their order does not matter. Use ol when the order is part of the instruction. Every item belongs in an li element. A list makes repeated information easier to scan and exposes the grouping to assistive technology.

## Worked example

```html
<ul>
  <li>Water</li>
</ul>
<ol>
  <li>Check the map</li>
</ol>
```
