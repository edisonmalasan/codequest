## Goal

Name a local fragment destination and its target section.

## Learn

An anchor can point to a section on the same page with a fragment such as #hours. The target element needs the matching ID. Link words should say where the link leads; “Opening hours” is clearer than “click here.” In this learning Preview, links are displayed but do not navigate. Check reads the safe fragment in your HTML source.

## Worked example

```html
<a href="#map">View the map</a>
<section id="map"><h2>Map</h2></section>
```
