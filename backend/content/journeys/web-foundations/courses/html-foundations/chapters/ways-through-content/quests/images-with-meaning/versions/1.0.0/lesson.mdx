## Goal

Give a supplied image a useful text alternative.

## Learn

An image needs alternate text that communicates its purpose. Describe what matters to this page, not every pixel. The supplied tiny map icon is local data, so Preview needs no network request. A decorative image would instead use an empty alt, but this map carries useful meaning. Check looks for the correct img element and its alternate text.

## Worked example

```html
<img src="data:image/png;base64,..." alt="Map marking the north gate">
```

## What Check examines

Check inspects the listed element types, text, and safe attributes in your source. Different valid surrounding markup can pass. It does not run scripts or judge unlisted visual polish. Preview links never navigate and forms never submit or save typed values. Check is local feedback; signed-in Submit requests backend acceptance before account progress and XP can change.
