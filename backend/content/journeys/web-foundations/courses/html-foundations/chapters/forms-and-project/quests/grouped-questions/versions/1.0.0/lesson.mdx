## Goal

Use fieldset and legend to explain a related input group.

## Learn

When several controls answer one question, fieldset gives them a group and legend names that group. Each field still needs its own label. This example uses a single text field so its structure stays clear. Preview is deliberately inert: it displays the field, but submitting, navigation, and saving typed answers are disabled.

## Worked example

```html
<fieldset><legend>Route choice</legend><label for="trail">Trail</label><input id="trail" type="text"></fieldset>
```
