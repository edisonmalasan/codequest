## Goal

Combine headings, landmarks, a local link, a figure, and a labeled field into one coherent page.

## Learn

A useful page combines small semantic choices. Begin with landmarks and a clear title, add a descriptive jump link to a real section, place an illustration with its caption, and make a related note field easy to identify. This project reviews the concepts you have used in earlier lessons. You do not need CSS or JavaScript. Preview displays the page but does not activate links or forms; Check inspects the declared markup only.

## Worked example

```html
<header><h1>Field guide</h1></header><main><section id="route"><h2>Route</h2></section></main>
```

## Your task

Finish a one-page river field guide. Use header `guide-head` with h1 `guide-title` reading `River field guide`, main `guide-main`, a descriptive link `route-link` reading `Read the route` with href `#route`, section `route` with h2 `route-heading` reading `The route`, figure `guide-figure` with image `guide-image` alt `Map showing the river crossing` and figcaption `guide-caption` reading `Crossing sketch`, and a label `note-label` reading `Observation` with for `note-field` plus a text input `note-field` named `observation`.

1. Edit index.html and keep the named IDs unique.
2. Choose Preview to inspect the static page; then choose Check for local feedback.
3. Read each failed case, correct the relevant element, and Check again.

## What Check examines

Check inspects the listed element types, text, and safe attributes in your source. Different valid surrounding markup can pass. It does not run scripts or judge unlisted visual polish. Preview links never navigate and forms never submit or save typed values. Check is local feedback; signed-in Submit requests backend acceptance before account progress and XP can change.

## Reflect

Explain in your own words why the chosen elements help someone understand this page. This reflection is not graded.
