## Goal

Connect a visible label to its input with matching for and id values.

## Learn

A visible label tells a reader what belongs in a field. Its for attribute must match the input’s id so a click or assistive technology can identify the pair. The field’s type describes the expected input. This form is for learning markup: Preview shows the controls but cannot submit or store what someone types.

## Worked example

```html
<label for="email">Email</label><input id="email" name="email" type="email">
```
