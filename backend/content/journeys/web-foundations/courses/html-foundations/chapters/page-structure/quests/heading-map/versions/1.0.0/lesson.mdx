## Goal

Use heading levels to show sections and subsections.

## Learn

Heading levels describe the outline of a page. Start with one h1 for the page. A major section can use h2, and a subsection of that section can use h3. A heading is not just a way to make text large: its level tells readers how ideas relate. Keep the wording short enough to scan.

## Worked example

```html
<h1>Trail guide</h1>
<h2>Before you go</h2>
<h3>Water</h3>
```
