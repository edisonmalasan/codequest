## Goal

Separate paragraphs and mark strong emphasis without losing meaning.

## Learn

A paragraph groups one idea. Use separate p elements when the idea changes. Strong emphasis marks information that matters, while em changes the stress of a phrase. These elements carry meaning even if a stylesheet later changes their appearance. Keep essential directions in ordinary text so they remain readable without styling.

## Worked example

```html
<p>Bring a notebook.</p>
<p><strong>Notice</strong> the details.</p>
```
