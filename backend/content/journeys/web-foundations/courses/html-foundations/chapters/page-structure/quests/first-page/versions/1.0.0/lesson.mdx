## Goal

Create a main region with a meaningful first heading.

## Learn

A page is a document with a purpose. The main element marks its central content; a level-one heading names that content. A clear heading helps someone scanning visually and someone moving by headings with assistive technology. You can add other text around these elements, but keep one main destination for this small page.

## Worked example

```html
<main><h1>Garden notes</h1><p>What changed today?</p></main>
```
