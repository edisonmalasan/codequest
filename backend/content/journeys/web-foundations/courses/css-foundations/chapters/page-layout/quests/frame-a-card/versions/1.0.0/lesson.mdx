# Frame a card

## Goal

Use border and padding to separate a specimen card from surrounding text.

## Learn

Every element occupies a box. Padding separates its content from the inside edge; a border marks that edge. Give the specimen record a visible frame while keeping the name and description as ordinary HTML.

## Worked example

```css
.sample {
  border-style: solid;
  border-width: 1px;
  padding: 1rem;
}
```

Without `border-style`, setting only a width may leave no visible line.

## Your task

Set `.specimen` to `border-style: solid`, `border-width: 2px`, and `padding: 1rem`. Check reads these three source declarations; Preview shows the resulting box.
