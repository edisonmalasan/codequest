# Choose the heading

## Goal

Use element and ID selectors to style distinct parts of a page.

## Learn

A tag selector reaches every element of that kind. An ID names one particular landmark. The supplied HTML already provides both kinds of target, so the stylesheet can change their appearance without changing the words.

## Worked example

```html
<p id="date">Wednesday</p>
```

```css
p {
  line-height: 1.5;
}
#date {
  color: navy;
}
```

The first rule reaches paragraphs; the second reaches the named date.
