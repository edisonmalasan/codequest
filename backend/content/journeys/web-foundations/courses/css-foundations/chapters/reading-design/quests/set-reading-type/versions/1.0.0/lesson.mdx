# Set reading type

## Goal

Choose a heading family and size that establish a reading hierarchy.

## Learn

Typography helps a reader see what begins a page and what explains it. A larger heading creates hierarchy; a serif face gives this guide a distinct voice. Leave the paragraphs as normal text so the title remains the clearest entry point.

## Worked example

```css
h2 {
  font-family: serif;
  font-size: 1.5rem;
}
```

`rem` follows the document root size. The example styles second-level headings; your task targets the page title.

## Your task

Set `h1` to `font-family: serif` and `font-size: 2rem`. Check compares these declared values; Preview reveals whether the title still fits.
