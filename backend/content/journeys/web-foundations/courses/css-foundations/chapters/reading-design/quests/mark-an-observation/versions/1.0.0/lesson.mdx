# Mark an observation

## Goal

Pair a dark text color with a light background on a note.

## Learn

Color can distinguish an observation without changing its meaning. The foreground must remain easy to read against its background. Dark navy on a light yellow gives this note a strong separation from the rest of the log.

## Worked example

```css
.warning {
  color: black;
  background-color: yellow;
}
```

A color pair belongs to one selector, so the text and its surface travel together.

## Your task

Give `.observation` `color: navy` and `background-color: yellow`. Check tests the declared pair. Preview it before moving on; Check does not measure contrast for arbitrary extra styles.
