## Goal

Calculate resource costs with multiplication, addition and explicit grouping.

## Learn

Arithmetic turns values into new values: `+` adds, `-` subtracts, `*` multiplies, and `/` divides. Multiplication happens before addition. Parentheses state a grouping explicitly: `(2 + 3) * 4` differs from `2 + 3 * 4`.

To buy a quantity at a unit price plus one delivery fee, multiply quantity by price, then add the fee once. Numbers must be numbers: adding to a quoted number can join text rather than calculate a total.

## Worked example

```js
const quantity = 2;
const price = 5;
const fee = 1;
console.log(quantity * price + fee);
```

## Your task

Calculate and print three orders: 3 items at 4 each plus fee 2; zero items at 4 each plus fee 2; and 2 items at 5 each with no fee. Replace the three placeholder expressions with arithmetic. The delivery fee applies even to the zero-item example.

## Check contract

All quantities, prices and fees here are nonnegative integers. Print only the three numeric totals, in task order; no currency symbol or label.

Complete console output, one value per line:

```text
14
2
10
```
