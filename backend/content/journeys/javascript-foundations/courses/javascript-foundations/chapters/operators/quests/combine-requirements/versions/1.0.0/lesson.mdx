## Goal

Combine two boolean requirements and format a readable status message.

## Learn

`&&` means both conditions must be true; `||` means either can be true. `!` reverses a boolean. For a trip that requires supplies and a map, a map alone is not enough. Compare each requirement first, then combine their results.

`+` also joins strings. When one side is text, JavaScript converts a boolean to text for the message. Add spaces and punctuation explicitly; string joining does not add them for you.

## Worked example

```js
const hasLamp = true;
const hasGuide = false;
console.log('Safe: ' + (hasLamp && hasGuide));
```

## Your task

A departure needs at least 2 supplies AND a map. Print `Ready: ` followed by the combined boolean for (2 supplies, map true), (1 supply, map true), and (2 supplies, map false). Keep the exact colon and space. Replace each placeholder || with the correct rule.

## Check contract

The minimum includes 2. Both requirements must hold. Each complete message occupies one line; Check includes the equal-threshold and missing-map examples.

Complete console output, one value per line:

```text

Ready: false

```
