## Goal

Repair overlapping branches so each input produces one exclusive category.

## Learn

Two separate if statements can both run. In a chain, an else belongs to the immediately preceding if. Indenting text does not change that relationship; use braces and read the actual structure.

A negative number uses a minus sign, such as -1. A supply count below zero means debt, exactly zero means empty, and a positive count means stock. These categories do not overlap. A trace should identify the first unexpected output, not just the final line.

## Worked example

```js
const number = 0;
if (number < 0) {
  console.log('Negative');
} else if (number === 0) {
  console.log('Zero');
} else {
  console.log('Positive');
}
```

## Your task

Repair the three starter decisions for -1, 0 and 1. Produce Debt, Empty and Stock respectively, with one line per input. Remove overlapping independent branches and correct which side owns zero. Run the defective version first if you want to inspect the extra output.

## If you get stuck

A syntax error means JavaScript could not read the program: inspect quotes, brackets and punctuation. A runtime error happens after it starts: inspect names and the failing operation. A failed check means the program ran but its behavior differs: compare the declared example with the observed result. Use the graduated hints one at a time.
