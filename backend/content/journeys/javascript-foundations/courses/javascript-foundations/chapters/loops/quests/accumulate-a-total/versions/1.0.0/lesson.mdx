## Goal

Accumulate a numeric sequence separately from the loop counter.

## Learn

An accumulator holds the combined result so far. Start a sum at zero, then add the current number each time: `total = total + number`. The loop counter tracks which number to visit; the accumulator tracks the sum.

Print the total after the loop to see the final result, rather than every partial result. For an empty sequence, no body runs and the total remains zero. This is a useful identity: adding nothing should not invent a cost.

## Worked example

```js
let total = 0;
for (let number = 1; number <= 2; number = number + 1) {
  total = total + number;
}
console.log(total);
```
