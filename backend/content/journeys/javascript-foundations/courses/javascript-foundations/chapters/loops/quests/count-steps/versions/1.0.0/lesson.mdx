## Goal

Run a finite counted loop and predict its first and last iterations.

## Learn

A for loop has initialization, condition and update: `for (let step = 1; step <= 2; step = step + 1)`. Initialization runs once. Before each iteration the condition is checked. After the body the update runs, then the condition is checked again.

A loop whose starting value already fails its condition performs zero iterations. The update must move toward stopping. `step = step + 1` adds one to the old value and stores the result. A missing update can cause a timeout.

## Worked example

```js
for (let step = 1; step <= 2; step = step + 1) {
  console.log(step);
}
```

## Your task

Change the first loop to print 1, 2 and 3 once each. The second represents a zero-step journey: it must print nothing. Keep the supplied start at 1 and update by 1. Correct the endpoint conditions rather than adding extra prints.

## Check contract

Only the first loop contributes output. The normal limit is 3; the boundary limit is 0, whose condition fails before the body. Loops must terminate.

Complete console output, one value per line:

```text
1
2
3
```

## If you get stuck

A syntax error means JavaScript could not read the program: inspect quotes, brackets and punctuation. A runtime error happens after it starts: inspect names and the failing operation. A failed check means the program ran but its behavior differs: compare the declared example with the observed result. Use the graduated hints one at a time. Keep loops bounded; a timeout stops the run and preserves your code.
