## Goal

Edit a supplied string and use Run to inspect its exact console output.

## Learn

The editor holds instructions; the console holds the result of running them. Clicking in the editor and changing text does not update old output until you choose Run again. A program is a sequence of instructions that JavaScript reads.

`console.log` prints a value. Text is a string: surround it with matching single or double quotes. The quotes mark where the string begins and ends; they are not printed. End this instruction with a semicolon. JavaScript is case-sensitive: `console` and `Console` are different names.

## Worked example

```js
console.log('Hello, explorer!');
```

## Your task

1. Click inside main.js. Replace only the words between the quotes with `I am ready to code!`.
2. Choose Run. Locate the console result and compare it with the target below.
3. Choose Check. If it fails, inspect capitalization, spaces, punctuation and additional printed lines.

## Check contract

Print exactly one line. Both normal and exact-output cases use this same sentence; there is no hidden input. Single and double quotes are both valid.

Complete console output, one value per line:

```text
I am ready to code!
```

## Run, Check, and acceptance

Run executes your current code and shows console output or errors. Check compares the declared behavior and reports local, unverified feedback; it does not submit your work. ## Reflect (ungraded)

How is editing the source different from running it? What would an unmatched quote do? Write or say your explanation for yourself. Check does not assess this reasoning.

## If you get stuck

A syntax error means JavaScript could not read the program: inspect quotes, brackets and punctuation. A runtime error happens after it starts: inspect names and the failing operation. A failed check means the program ran but its behavior differs: compare the declared example with the observed result. Use the graduated hints one at a time. Keep loops bounded; a timeout stops the run and preserves your code.
