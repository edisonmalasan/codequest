## Goal

Return an exclusive score category for each function argument.

## Learn

Moving a decision into a function removes repeated branch blocks. The parameter supplies the score for each call; do not replace it with one example value inside the body. Every allowed path must return a category.

A return ends that call. You can use an if/else chain or early returns; both can implement the same behavior. Compare exact threshold inputs before assuming the normal case proves the boundary.

## Worked example

```js
function temperatureLabel(value) {
  if (value >= 20) {
    return 'Warm';
  }
  return 'Cool';
}
console.log(temperatureLabel(20));
```

## Your task

Implement `scoreCategory(score)` with the same contract as Q09: Gold at 80 or more, Silver from 50 through 79, and Practice below 50. Return the exact string for the supplied parameter; do not print the category instead.

## Check contract

Inputs are integers from 0 through 100. Both thresholds are inclusive in their higher category. Check varies the score and compares exact returned strings.

- `scoreCategory(49)` returns `"Practice"`.
- `scoreCategory(50)` returns `"Silver"`.
- `scoreCategory(79)` returns `"Silver"`.
- `scoreCategory(80)` returns `"Gold"`.
- `scoreCategory(100)` returns `"Gold"`.
- `scoreCategory(0)` returns `"Practice"`.

A failed check means the program ran but its behavior differs: compare the declared example with the observed result. Use the graduated hints one at a time.
