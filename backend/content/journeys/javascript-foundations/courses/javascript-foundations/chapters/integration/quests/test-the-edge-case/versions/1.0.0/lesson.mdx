## Goal

Find an empty-input defect and verify a collection helper at boundaries.

## Learn

A useful test challenges an assumption. Reading the first array element assumes at least one element exists. The empty array disproves that assumption before a loop can repair the result.

For nonnegative stock counts, zero can be the empty maximum. Initialize from the contract, then compare each value with the greatest seen so far. A revealing test includes an input, predicted result and explanation of why the defective program differs. Check verifies behavior, not that explanation.

## Worked example

```js
function smallestOrZero(values) {
  if (values.length === 0) {
    return 0;
  }
  let smallest = values[0];
  for (let i = 1; i < values.length; i = i + 1) {
    if (values[i] < smallest) {
      smallest = values[i];
    }
  }
  return smallest;
}
```

## Check contract

Input contains zero to 20 nonnegative integers. Empty returns numeric 0, not undefined. All-zero input also returns 0. The maximum may be first, middle or last; duplicates are valid.

- `largestStock([2, 7, 4])` returns `7`.
- `largestStock([])` returns `0`.
- `largestStock([0])` returns `0`.
- `largestStock([1, 1, 5])` returns `5`.
- `largestStock([9, 2, 2])` returns `9`.
