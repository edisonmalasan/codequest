## Goal

Use precise inclusive comparisons and strict equality at a threshold.

## Learn

A comparison returns a boolean. `>` excludes equality and `>=` includes it; `<` and `<=` work similarly. `===` compares values without converting their types, while `=` changes a binding.

An inclusive minimum of 10 admits exactly 10. Test one below, equal and one above to expose a boundary mistake. Strict equality makes the number 10 different from the string "10".

## Worked example

```js
console.log(6 >= 6);
console.log(5 >= 6);
console.log(6 === '6');
```

## Your task

Replace the starter comparisons to print whether 9, 10 and 11 each meet a minimum of 10. Then compare the number 10 with the string "10" using strict equality. Print each boolean on its own line.

## Check contract

The minimum is inclusive. The final comparison must keep the values as the supplied number and string; there is no type conversion.

Complete console output, one value per line:

```text

true
true
false
```
