## Goal

Select exactly one of two messages using an if/else branch.

## Learn

`if (condition) { ... } else { ... }` chooses a block. The first block runs when the condition is true; otherwise the else block runs. Braces surround each block and the condition belongs inside parentheses.

Trace one example at a time. An if/else pair chooses exactly one path, so a single decision should not print both messages. An assignment inside the condition can change state instead of checking it.

## Worked example

```js
const lit = false;
if (lit) {
  console.log('Light');
} else {
  console.log('Dark');
}
```

## If you get stuck

A syntax error means JavaScript could not read the program: inspect quotes, brackets and punctuation. A runtime error happens after it starts: inspect names and the failing operation. A failed check means the program ran but its behavior differs: compare the declared example with the observed result. Use the graduated hints one at a time.
