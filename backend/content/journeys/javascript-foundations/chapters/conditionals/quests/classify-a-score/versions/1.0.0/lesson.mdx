## Goal

Order score branches and include exact threshold values.

## Learn

Use `else if` when there are more than two exclusive choices. Conditions are considered in order; the first matching branch runs and the rest of that chain are skipped. An unconditional else catches the remaining cases.

If a high score also satisfies a lower minimum, check the higher minimum first. Otherwise the lower branch captures it. Boundary tests at exactly each threshold expose an accidental strict > comparison.

## Worked example

```js
const temperature = 12;
if (temperature >= 20) {
  console.log('Warm');
} else if (temperature >= 10) {
  console.log('Mild');
} else {
  console.log('Cool');
}
```

## Your task

Repair the five score blocks. Scores 80 or more are Gold, 50 through 79 are Silver, and below 50 are Practice. Inspect the comparison at both inclusive thresholds. The supplied examples are 49, 50, 79, 80 and 81, in that order.

## Check contract

Scores are nonnegative integers for this task. Print exactly one category per example. Each threshold belongs to the higher category.

Complete console output, one value per line:
