## Goal

Read and update named properties in an item record.

## Learn

An object groups named properties inside braces, such as `{ name: "rope", count: 2 }`. Read a known property with dot notation: `item.count`. An array index expresses position; a property name expresses meaning.

A returned object is useful when one result has several related fields. Build it with the required names so callers know what to read. Updating count should not accidentally rename the item or produce text from a quoted number.

## Worked example

```js
const item = { name: 'key', count: 1 };
item.count = item.count + 2;
console.log(item.name);
console.log(item.count);
```

## Your task

Implement `restock(item, amount)`. Return an object with exactly name and count: keep item.name and add amount to item.count. Repair the starter's wrong property spelling and use the supplied amount. You may construct a result object before updating its count.

## Check contract

item has a string name and nonnegative integer count; amount is a nonnegative integer. Return exactly the two named fields. Adding zero preserves count, and a zero initial count is valid. Input mutation is not graded here; result shape and values are.

- `restock({"name": "rope", "count": 2}, 3)` returns `{"name": "rope", "count": 5}`.
- `restock({"name": "map", "count": 4}, 0)` returns `{"name": "map", "count": 4}`.
- `restock({"name": "lamp", "count": 0}, 2)` returns `{"name": "lamp", "count": 2}`.
