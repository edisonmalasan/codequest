## Goal

Select available record names while preserving the original order.

## Learn

An array can contain objects. Read `items[i]` to get a record, then its named quantity property to decide whether it qualifies. Put selected names into a separate result array so a zero-quantity record is not reported as available.

`result.push(value)` appends a value to an array. Start with `[]`, scan from the first record to the last, and append only when the condition holds. This preserves order and keeps repeated names if two records qualify.

## Worked example

```js
const items = [
  { name: 'key', quantity: 1 },
  { name: 'map', quantity: 0 },
];
const selected = [];
for (let i = 0; i < items.length; i = i + 1) {
  if (items[i].quantity > 0) {
    selected.push(items[i].name);
  }
}
console.log(selected);
```

## Your task

Implement `availableNames(items)` returning an array of names for records whose quantity is strictly greater than zero. Keep input order and include each qualifying record, even if names repeat. Correct the starter that includes zero stock.

## Check contract

Input has zero to 20 records with string name and nonnegative integer quantity. Return an array of strings, not a joined message. Empty input or no available records returns []. Quantity zero is excluded; do not sort or deduplicate.

- `availableNames([{"name": "rope", "quantity": 2}, {"name": "map", "quantity": 0}, {"name": "lamp", "quantity": 1}])` returns `["rope", "lamp"]`.
- `availableNames([])` returns `[]`.
- `availableNames([{"name": "key", "quantity": 0}])` returns `[]`.
- `availableNames([{"name": "rope", "quantity": 1}, {"name": "rope", "quantity": 2}])` returns `["rope", "rope"]`.
