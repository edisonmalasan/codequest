## Goal

Return a total by visiting every array element, including the last.

## Learn

Combine a counted loop with an array: indices run from 0 while index is less than length. An array of length 3 has indices 0, 1 and 2; index 3 is outside it. Add the element at the current index, not the index itself.

An empty array has length zero. A correctly initialized accumulator returns zero without entering the body. Testing empty, single and several values helps separate initialization, indexing and endpoint mistakes.

## Worked example

```js
const costs = [2, 5];
let total = 0;
for (let i = 0; i < costs.length; i = i + 1) {
  total = total + costs[i];
}
console.log(total);
```

## Your task

Implement `sumNumbers(numbers)` to return the sum of every supplied array value. Correct the starter that adds the index instead of the element. Do not assume an array always has three elements or a nonempty first element.

## Check contract

Arrays contain zero to 20 integers, each between -100 and 100. Empty returns 0; negative values subtract from the total. Return a number and leave the input available to the caller.

- `sumNumbers([2, 5, 3])` returns `10`.
- `sumNumbers([])` returns `0`.
- `sumNumbers([7])` returns `7`.
- `sumNumbers([-2, 5, 0])` returns `3`.
