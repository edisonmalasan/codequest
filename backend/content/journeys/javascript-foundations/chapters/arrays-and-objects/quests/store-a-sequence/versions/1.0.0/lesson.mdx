## Goal

Construct an array, update an indexed element and read its length.

## Learn

An array groups ordered values inside square brackets. Indices start at 0: in `["key", "map"]`, index 0 holds key and index 1 holds map. `items.length` counts elements, so the last valid index is length minus one.

Read an element with `items[index]` and update it with assignment. A const binding can refer to an array whose elements change: const prevents replacing the binding, not editing the referenced array. Empty text is still a valid element, not an absent slot.

## Worked example

```js
const items = ['key', 'map'];
items[1] = 'lamp';
console.log(items.length);
console.log(items[0]);
console.log(items[1]);
```
