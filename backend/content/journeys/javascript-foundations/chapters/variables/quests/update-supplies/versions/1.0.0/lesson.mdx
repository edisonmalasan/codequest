## Goal

Reassign a changing supply counter while preserving an unchanged label.

## Learn

Use `let` when a named value changes. In `let coins = 5; coins = 2;`, the second statement replaces the value; it does not declare a second binding. Use `const` for a label that stays the same.

`=` assigns the value on the right to the name on the left. Reassigning a const throws a runtime error. Read a state trace top to bottom: after each assignment, the next statement sees the new value.

## Worked example

```js
let coins = 5;
console.log(coins);
coins = 2;
console.log(coins);
```

## If you get stuck

A syntax error means JavaScript could not read the program: inspect quotes, brackets and punctuation. A runtime error happens after it starts: inspect names and the failing operation. A failed check means the program ran but its behavior differs: compare the declared example with the observed result. Use the graduated hints one at a time.
