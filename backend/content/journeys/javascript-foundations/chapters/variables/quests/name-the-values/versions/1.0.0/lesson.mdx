## Goal

Bind number, string and boolean values and inspect their types.

## Learn

A binding gives a value a name. `const lanterns = 3;` binds the number 3 to `lanterns`; use that name later without quotes. Choose meaningful names that start with a letter and contain no spaces. A number is written without quotes, a string with quotes, and a boolean as `true` or `false`.

`typeof` reports a value's type as text. For example, `typeof 3` is `number`, while `typeof "3"` is `string`. Zero is still a number. `const` means the binding cannot be reassigned; it does not turn a number into text.

## Worked example

```js
const lanterns = 3;
console.log(lanterns);
console.log(typeof lanterns);
```
