# First message

This is a **draft authoring example**, not a published quest. A quoted string is text that JavaScript can display. The editor holds your source; the console shows what your source prints after you press Run.

For example, `console.log('Hello!')` prints `Hello!` in the console. The quote marks are part of the code, not part of the printed line.

## Your task

Change the supplied string so the console prints exactly `I am ready to code!`. Press Run and compare the result. Then try Check. Capital letters, spaces, and the exclamation mark matter; an extra printed line is not the same result.

If the console reports a syntax error, look at the quote marks. If it prints the old message, compare your editor text with the required message. A failed check is feedback you can use to revise the code.
