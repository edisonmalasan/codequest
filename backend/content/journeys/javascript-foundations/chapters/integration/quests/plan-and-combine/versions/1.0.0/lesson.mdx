## Goal

Decompose an inventory summary into independently testable helpers.

## Learn

A prose requirement often describes several results. Separate the meanings before coding: total units is the sum of quantities, while available records counts how many records have a positive quantity. A single record with quantity 4 contributes four units but one available record.

Give those responsibilities separate helpers, then combine their returned numbers into an object. Start with a hand-worked example, test each helper, and inspect the final object. Empty input is a complete input with zero results, not an error. This small integration task prepares for the separately planned capstone.

## Worked example

```js
function countRecords(items) {
  return items.length;
}
function describeRecords(items) {
  return { records: countRecords(items) };
}
console.log(describeRecords([{ name: 'key', quantity: 2 }]));
```

## Your task

Implement `stockTotal(items)`, `availableCount(items)` and `inventorySummary(items)`. The first sums quantity. The second counts records with quantity greater than zero. The third returns exactly `{ total: ..., available: ... }` using the helper results. Keep the signatures. Plan each helper's role and choose your own revealing example before Check.

## Check contract

Input contains zero to 20 records, each with string name and nonnegative integer quantity. Duplicate names still represent separate records. Return numbers from the helpers and exactly total/available from the summary. Empty input gives both zero. This is not the capstone or a graded written explanation.

- `stockTotal([{"name": "rope", "quantity": 2}, {"name": "map", "quantity": 0}, {"name": "lamp", "quantity": 3}])` returns `5`.
- `stockTotal([])` returns `0`.
- `availableCount([{"name": "rope", "quantity": 2}, {"name": "map", "quantity": 0}, {"name": "lamp", "quantity": 3}])` returns `2`.
- `availableCount([{"name": "key", "quantity": 0}])` returns `0`.
- `inventorySummary([{"name": "rope", "quantity": 2}, {"name": "map", "quantity": 0}, {"name": "lamp", "quantity": 3}])` returns `{"total": 5, "available": 2}`.
- `inventorySummary([])` returns `{"total": 0, "available": 0}`.
- `inventorySummary([{"name": "key", "quantity": 4}])` returns `{"total": 4, "available": 1}`.

## If you get stuck

A syntax error means JavaScript could not read the program: inspect quotes, brackets and punctuation. A runtime error happens after it starts: inspect names and the failing operation. A failed check means the program ran but its behavior differs: compare the declared example with the observed result. Use the graduated hints one at a time. Keep loops bounded; a timeout stops the run and preserves your code.
