## Goal

Return a calculated value from a function that accepts changing inputs.

## Learn

A function names a reusable operation. Parameters are local names for the arguments passed at a call. In `function addFee(price) { return price + 2; }`, calling `addFee(3)` gives 5 and `addFee(0)` gives 2.

`return` supplies the result to the caller and ends the function. Printing a result is not returning it; a function that only calls console.log returns undefined. Check calls your named function with separate inputs, so one fixed answer cannot satisfy the contract.

## Worked example

```js
function addFee(price) {
  return price + 2;
}
console.log(addFee(3));
console.log(addFee(0));
```
