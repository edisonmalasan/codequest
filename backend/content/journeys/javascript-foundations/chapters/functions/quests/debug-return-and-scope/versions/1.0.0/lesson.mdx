## Goal

Keep an accumulator local to each function call and return its final result.

## Learn

A binding created inside a function belongs to that call. A binding outside can survive between calls in the same run. If a sum should start fresh every time, initialize its accumulator inside the function.

Missing return is a separate defect: the calculation may happen and even print correctly, but the caller receives undefined. Diagnose lifetime and return independently. Isolated Check cases start fresh; use the supplied repeated-call Run example to inspect cross-call behavior too.

## Worked example

```js
function countSteps(limit) {
  let count = 0;
  for (let n = 1; n <= limit; n = n + 1) {
    count = count + 1;
  }
  return count;
}
console.log(countSteps(2));
console.log(countSteps(2));
```

## Your task

Repair `sumSteps(limit)` so each call returns the inclusive sum from 1 through limit, independently. Move the accumulator to the appropriate scope and add the missing return. Keep `repeatTotals(limit)`, which calls sumSteps twice and returns their sum; Check uses it to exercise repeated calls in a single Worker.

## Check contract

Limits are integers 0 through 100. sumSteps(0) returns 0. repeatTotals adds two independent returned sums; it is not twice a shared accumulator. Return numbers in all cases.

- `sumSteps(3)` returns `6`.
- `sumSteps(0)` returns `0`.
- `repeatTotals(3)` returns `12`.
- `repeatTotals(0)` returns `0`.
- `repeatTotals(1)` returns `2`.
