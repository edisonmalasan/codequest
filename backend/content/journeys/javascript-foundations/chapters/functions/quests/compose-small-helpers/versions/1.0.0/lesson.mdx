## Goal

Combine a numeric helper and a formatter with distinct responsibilities.

## Learn

A function can call another function and use its returned value. Keep each helper responsible for one thing: one computes a number, another turns a number into a message, and an outer function coordinates them.

Testing helpers separately can locate a defect that a final message alone would hide. Give each helper the argument it needs. A formatter should not sum again; otherwise two functions disagree about the same calculation.

## Worked example

```js
function double(value) {
  return value * 2;
}
function describe(value) {
  return 'Value: ' + value;
}
function report(value) {
  return describe(double(value));
}
```

## Your task

Implement all three supplied functions. `stepTotal(limit)` returns the sum 1 through limit. `formatTotal(total)` returns the string `Total: ` plus the number. `journeyReport(limit)` combines their results to return the report. Keep the supplied names and test helpers individually with Run before Check.

## Check contract

Limits and formatter values are nonnegative integers, with limits from 0 through 100. Sum endpoints inclusively; zero has total 0. The report prefix has exactly one space after the colon. Each helper is independently checked.

- `stepTotal(4)` returns `10`.
- `stepTotal(0)` returns `0`.
- `formatTotal(5)` returns `"Total: 5"`.
- `journeyReport(3)` returns `"Total: 6"`.
- `journeyReport(0)` returns `"Total: 0"`.

## If you get stuck

A syntax error means JavaScript could not read the program: inspect quotes, brackets and punctuation. A runtime error happens after it starts: inspect names and the failing operation. A failed check means the program ran but its behavior differs: compare the declared example with the observed result. Use the graduated hints one at a time. Keep loops bounded; a timeout stops the run and preserves your code.
