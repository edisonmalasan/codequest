## Goal

Use a condition-controlled loop whose update reaches a stopping state.

## Learn

A while loop checks its condition before each iteration. Unlike for, its changing state is usually initialized before the loop and updated inside the body. Ask what must change to make the condition false.

If the state is already ready, the body should not run. Check that boundary before trusting the normal path. Keep the update and the condition consistent; resetting the state in the body can prevent progress toward termination.

## Worked example

```js
let water = 0;
while (water < 2) {
  water = water + 1;
}
console.log(water);
```

## Your task

Energy must reach 3. In the first scenario it starts at 0; in the second it already starts at 3. Complete both conditions and updates to stop at exactly 3, then print only each final energy. Do not print every iteration.

## Check contract

Each update adds exactly 1. Stop when energy reaches 3; the already-ready boundary performs zero updates. Both loops must be finite.

Complete console output, one value per line:

```text

3
```
