# Proposal

## Why

Phase 39 calls for observing real learners, but the Phase 38 readiness decision remains NO GO. The team can prepare a reproducible study protocol and dry-run its evidence handling without recruiting learners, choosing F05 targets on behalf of the product owner, or collecting data before F06 is approved.

## What Changes

- Add a private-beta field protocol covering the eight roadmap focus areas: lesson clarity, exercise difficulty, validation accuracy, editor usability, mobile friction, meaningful return, hint usage, and capstone completion.
- Define synthetic rehearsal steps, source and trust labels, participant observation and issue-triage templates, and a weekly pattern review that does not treat individual feature requests as decisions.
- Add an explicit launch checklist that binds the study to the Phase 38 NO GO matrix and reserves F04/F05/F06 choices for their owners.
- Update the roadmap to distinguish study preparation from an operating private beta.

## Capabilities

### New Capabilities

None. This change adds operational documentation and does not change application behavior or a canonical requirement.

### Modified Capabilities

None. Existing `learning-analytics`, `beta-preparation`, and learning authority specifications remain controlling.

## Impact

Documentation and OpenSpec planning artifacts only. No API, database, frontend, telemetry configuration, recruitment, external account, learner data, or release status changes.
